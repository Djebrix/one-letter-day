Exactly one letter, written to `/output/entry.txt` by a small deterministic Python program. See the competition at https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36.

## Run

```sh
python3 main.py
```

This writes the letter to `entry.txt` inside `$ENTRY_OUTPUT_DIR` (default `/output`). Standard library only, no network, deterministic.
